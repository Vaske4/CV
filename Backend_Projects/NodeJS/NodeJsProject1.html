What I Learned

The building blocks of a production-shaped Node backend, worked through one at a time.

Node & Express app setup

Initialising a Node.js server, configuring npm packages and setting up a scalable Express application.

TypeScript & modern JS

Using TypeScript for type safety and interfaces, plus modern ES6+ features like arrow functions and destructuring.

Routing & endpoints

Defining RESTful routes and HTTP methods (GET, POST, PUT, DELETE) and modularising them with the Express router.

Requests & responses

Processing incoming requests (body, query, params) and returning correct HTTP responses and status codes.

Request validation

Validating user input with middleware such as express-validator to keep the data consistent.

Database communication

Persisting data in NoSQL (MongoDB/Mongoose) as well as relational databases (MySQL/Sequelize).

Files, uploads, downloads

Implementing file uploads (with Multer), managing stored files and serving downloads.

Auth & REST security

Authentication, session handling via cookies, CSRF protection and JSON Web Tokens.

The hard part

Challenges & Solutions

Asynchronous data handling

The genuinely interesting challenge was fully understanding the asynchronous nature of Node.js and guaranteeing efficient data synchronisation with the frontend.

What it taught me

  • Thinking in promises and async/await instead of nested callbacks
  • Keeping the order of database operations predictable
  • Handling errors in asynchronous middleware chains

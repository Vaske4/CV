Project Overview

A semester project at FH JOANNEUM: take a web application and bring it to production on Kubernetes with an automated, GitOps-driven delivery pipeline.

The Assignment

In a team of four students supervised by one lecturer, we had to deploy a web application (similar to YeahBuddy) on a Kubernetes cluster and build a complete CI/CD pipeline around it.

The codebase lived in a GitLab repository. GitLab CI handled build and test, the resulting Docker image was pushed to the GitLab Container Registry, and ArgoCD and Rancher Fleet pulled that image to deploy and deliver the application to the cluster.

Part of the assignment was a direct comparison of ArgoCD and Rancher Fleet to determine which tool was the better fit.

GitOps Delivery

Instead of pushing changes into the cluster, ArgoCD and Rancher Fleet continuously watch the Git repository and pull the desired state. Git stays the single source of truth for the deployment.

ArgoCD vs. Rancher Fleet

We configured and evaluated both tools side by side — setup effort, quality of the UI and its sync feedback, multi-cluster handling, and how transparent rollbacks were — and derived a recommendation from the comparison.

Leadership & Project Management

As Team Lead I owned the project management side of the work. Beyond the technical implementation, I was responsible for structuring the work, keeping the team aligned, and maintaining a clear view of progress at all times.

I set up and ran the project in Jira: I broke the assignment down into epics, wrote the user stories, maintained a Kanban board to visualize the flow of work, and built a timeline with the milestones we had to hit.

What I owned

  • Set up and administered the Jira project workspace
  • Broke the assignment down into epics and wrote the user stories
  • Built and maintained a Kanban board to visualize work in progress
  • Created the project timeline and tracked the milestones
  • Delegated tasks across the team and unblocked teammates
  • Kept a continuous overview of scope, progress and priorities
  • Reported progress to and coordinated with our supervisor

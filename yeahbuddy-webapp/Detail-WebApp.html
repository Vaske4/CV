Learnings

What I Took Away

This was the project where the pieces of a server-rendered web application finally clicked into place — how a request travels from a route through a controller to a template, and where the database fits in.

  • Routing
  • Working with the MVC pattern
  • Connecting the application to a database
  • How a REST API actually works
  • SQL injection and how templates have to guard against it
  • Dynamic variables inside HTML templates
  • Bootstrap for the layout
  • Working together in GitLab

Challenges

The three things that cost us the most time during development.

Tying the features together

Each screen worked on its own; making them share state and flow into one another was the harder half.

Using the database properly

Modelling the data so that workouts, plans and history could be queried without fighting the schema.

Merging in GitLab

Several people in the same files — learning to branch, review and resolve conflicts without losing work.
